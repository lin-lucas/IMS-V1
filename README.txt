仓储物品管理系统V1.8.1 使用说明
1. 项目路径
ROOT
\---仓储物品管理系统V1.8.1
    |   IMS.exe
    |
    \---_internal
        |   
        \---lang
                en_us.json
                zh_cn.json
说明：
- ROOT为项目根目录
- IMS.exe为程序运行文件（想运行就点它）
- _internal为内部文件夹，其中lang为语言文件目录
-- ！！！_internal文件夹【非常重要】，请【不要】手欠删除！！！
2. 运行程序
双击运行IMS.exe，程序将自动打开。
3. 登录
初次使用请先注册，注册成功后即可自动登录。
4. 功能介绍（需先在第3步中登录）
系统主要功能包括：
- 添加物品
- 删除物品
- 查询物品
- 查询索引
- 导出日志
- 退出程序
详见命令页面（登录后输入‘h’查看）。
5. 提示与技巧
- 输入“h”查看命令页面
- 输入“q”退出程序
- 输入“cls”清屏
- 系统日志文件为“_internal\logs.log”，可查看。
- 如程序报错，麻烦发个issue给我，谢谢！:-)
